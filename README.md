# 황폐한 아웃랜드

황폐한 아웃랜드(Ashes of Outland) 카드 데이터입니다.


## README: API 관리·편집 규칙 (2026-11-14)

- 배포용 필수 자료: `cards.json` 카드 목록, `data/<카드ID>.json` 최초 사용 및 날짜별 카드 정보, `art/`, `golden/`, `frame/`의 일반·황금 원화와 애니메이션·프레임 데이터. 없는 원본은 지어내지 않습니다.
- `render.json`, `history.json`, `cards-date.json`, `render-date.json`, `history-date.json`은 중복 집계·호환 산출물이므로 저장소에 다시 커밋하지 않습니다. 생성되더라도 검증용 임시 출력으로만 사용합니다.
- 데이터가 날짜별 키로 작성되지 않았다면 실제 한국 날짜 근거를 보존하는 무손실 변환을 먼저 해야 합니다. 최초 사용일은 베타 북미 실사용의 KST 변환, 모험 지구 개방일, 이벤트 실제 개시일로 구분합니다. 토큰 포함, 잘못된 앞선 날짜 키는 삭제합니다.
- 이후 기록은 변경 필드만 기입합니다. 표시 줄바꿈은 `<br></br>`, 원시 증거 개행은 유지합니다. 프레임·황금 재질·애니메이션 원본 바이너리는 임의 수정하지 않습니다.
- `.github/`, `tools/`, `release-policy.json` 등 검증·재빌드에 필요한 파일은 의존성을 확인하기 전에 지우지 않습니다. 새 schema/legacy 호환 래퍼를 추가하지 않습니다.
